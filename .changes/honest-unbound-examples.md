`doctor`'s "unbound examples" count now means what it says: an example that could have been bound to a prop with a fixed set of string options and wasn't, counted once per grid axis or list item instead of once per item. Axes and examples that vary a boolean, a number, a node, several props or a composition can't be bound and are no longer counted, so the figure in `summary.unboundExamples` drops for every existing project, typically to 0 once its pages are authored, instead of rising with each page added. It is still informational: never an issue, never in the exit code. The count is also no longer printed on the human summary line (it now ends after the `(N with examples)` clause): once honest it reads 0 for a fully authored project, and a number that is nearly always zero beside errors and warnings implied a backlog that does not exist. It stays in `--json` as `summary.unboundExamples`, unchanged in shape.
