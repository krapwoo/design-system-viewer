The starter kit's components now report their state to web screen readers and `Shimmer` restarts its pulse: every `accessibilityState` became React Native's cross-platform `aria-checked` / `aria-selected` / `aria-disabled` / `aria-busy` / `aria-expanded` (react-native-web ignores `accessibilityState`, so checkboxes, switches, radios, tabs and loading states were silent on web), `Radio` reports `aria-checked` instead of selected, `ProgressDots` reports `aria-valuemin` / `aria-valuemax` / `aria-valuenow`, `EmptyState`'s decorative icon is `aria-hidden`, and `Shimmer`'s shared pulse is reference-counted so skeletons pulse again after every Shimmer has unmounted. **Breaking:** `FieldContainer`'s `accessibilityState` prop is replaced by `aria-disabled` and `aria-expanded`, and `Card`'s `accessibilityState` prop by `aria-busy`, `aria-checked`, `aria-expanded` and `aria-selected`; pass those instead.
