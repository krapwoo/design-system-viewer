Six corrections from the successor review, all defects in this branch.

**The restart flag was cleared before the restart finished.** `restartingMetro` was reset at the top of the exit handler, before waiting for the port and respawning. A repair firing in that window found no live child to kill and left the flag set with nothing pending — after which the next genuine Metro crash would be mistaken for a deliberate restart and silently respawned, skipping the shutdown path that releases the watchers and the dev lock. Worse, an Update arriving in that state could spawn two Metros on one port. The flag now stays set until the new child is bound, which also stops a second repair stacking a restart on the first.

**A port that never frees said nothing.** The wait gives up after five seconds and spawns anyway — a catalog that tried and failed to come back is recoverable, one that silently never tries is not — but it now says so rather than looking like a clean restart.

**`singleTallSpecimen` only looked at the first block.** The rule is "a single specimen taller than its column", which says nothing about order, yet the same two blocks placed variants-then-states and states-then-variants got different answers. Either block can now earn the split, with a test pinning both orders.

**Restoring `sampleWidth`'s default would have capped the measured lane.** With `280` back as a fallback, a row inside a `TokenRowGroup` was pinned to 280 on the first frame, and a measurement taken through that constraint can never report wider — so the lane that exists to grow to the widest sample could never exceed 280, and a type scale's `display` sample needs more. Inside a group the lane now governs alone; `sampleWidth` applies only to a row standing on its own, which is the case it was restored for. Verified rendered: the notes still align in one column and the 88px `display` sample spans ~333px.

**A standalone row's sample stopped stretching.** The inner wrapper sits at its natural width so it can report what the sample takes, which is only needed while measuring. Standing alone there is nothing to report, so it stretches to the column again — otherwise a sample sized as a percentage collapses to nothing.

**The README claimed more than the rule does.** It now says the rule visits list cells only — matrix (`ComparisonGrid`) cells use `role=table` and are never measured — and names the trade-off in treating `hidden` as containment: a full-width component clipping its own corners hides a genuinely too-narrow cell from this rule. That is the price of staying quiet about carousels and shimmer sweeps, and it should be visible rather than implied.
