Motion pages can preview SwiftUI transitions, category pages get ready-made inventories, and token grids are checked for order:
- `MotionSpecimen` has a `kind: 'transition'` that previews a SwiftUI `.transition(...)`. Give it `transition` (`opacity`, `identity`, `move`, `slide`, `push`, `scale`, `offset`, `combined`, `asymmetric`, for example `{ type: 'move', edge: 'bottom' }`) and, optionally, an `animation`; `animation` is the animation of the change that inserts or removes the view; leave it out and the specimen assumes `withAnimation` with no argument on iOS 17+ (a spring, response 0.55, no bounce) and says so under the stage. A sample view rests inserted, with no animation on load; Replay removes it, holds the empty stage, then inserts it again. With Reduce Motion on it stays inserted, Replay does not animate, and a note says so. The starter kit's Motion page has an example of each.
- New `InventoryGroup` and `InventoryTile` draw a category overview page's inventory from data: groups of flat tiles, each the member's real specimen with its title linking to its page. The title is the page's or member's own title, never an id, and a member with no title shows a readable name. Three or five tiles sit three across. Every tile sits on the same grey specimen stage (pass `surface` for a dark or white one). One tab stop per tile; the specimen is hidden and inert. The README has a new "Category overview pages" section and the starter kit's Buttons page uses them.
- A `TokenGrid` now warns in development, and `doctor --render` reports a `token-grid-order` warning, when two tiles share a `name` or when tiles whose names start with a number (`4pt`, `0.25s`, `22 × 22`) are not in ascending order. `order="authored"` keeps a deliberate order. The README token-page guidance now says one tile per value, smallest to largest.
- The README has a new "Using the app's own images" section: add the app's asset folder to `watchFolders` in your project's `metro.config.js`, then `require` the image from a catalog page. A test now proves the generated workspace config keeps those folders.
